# TPHS Gazette Tracker

TPHS Gazette Tracker is a real-time team management dashboard built to streamline collaboration, task tracking, and organisational visibility for student-led editorial teams.

## Key Features

- Centralised dashboard
- Task and issue tracking
- Kanban-style workflow
- Attendance monitoring
- Calendar scheduling
- Archive and analytics views

## Architecture

- Frontend: HTML, CSS, JavaScript
- Backend: Firebase Authentication and Firestore

## Purpose

This project was created to reduce operational friction and improve accountability within collaborative student organisations.

## Future Scope

- Role-based permissions
- Automated notifications
- Exportable performance reports
